# PP Launcher v8.1

## Requisitos

- Python 3.9+
- GTK4 y PyGObject
- xdg-utils

## Instalación

### Dependencias (Ubuntu/Debian)

```bash
sudo apt install python3-gi gir1.2-gtk-4.0 xdg-utils
```

### Dependencias (Arch / Manjaro)

```bash
sudo pacman -S gtk4 python-gobject xdg-utils
```

### Ejecutar

```bash
cd PP
python3 gtk_launcher.py
```
